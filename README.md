# MyTarget

证券研究资料与报告归档。

研究项目位于 `outputs/investment_research_20261009/`：

- `data/`：研究源资料、原始证据与结构化数据。
- `research/`：研究文本。
- `deliverables/`：Word、PDF 和 Excel 报告。
- `qa/`：审核记录、检查结果与辅助图表。
- `tools/`：研究处理、报告生成与检查脚本。

外部依赖、Python 字节码缓存、报告分页渲染缓存和 `*.inspect.ndjson` 检查临时文件由 `.gitignore` 排除，保留在本地。

当前研究数据版本为 `63ca87a2011995a6`，价格和资料截止日为2026年10月9日。92家公司、96个股票证券已完成整合，91个证券参加四期限排名，5个证券保留条件研究且暂不排名。92家正文均通过不少于1万有效汉字检查；总有效汉字约128.6万。

完整研究初版已交付：1份Excel、1卷总报告及12卷公司深研，每卷提供Word与同源PDF，共27份文件。13卷PDF共1,960页。内容覆盖、有效字数、模型计算、跨格式数字、来源、输入刷新及全部页面可读性验收通过；最终清单与文件SHA256见 `outputs/investment_research_20261009/qa/final_delivery_manifest.json`。

研究网页位于 `outputs/investment_research_20261009/web/index.html`，可直接双击离线打开。支持搜索92家公司、四期限排名、96证券详情与A/H切换、最多4项比较、真实历史K线、完整正文及来源。网页数字与冻结研究模型通过86,349项检查；96证券结论页、手机布局及全部27个下载链接通过浏览器验证。

五个条件证券为英矽智能、开拓药业、微创医疗、微创脑科学和微创机器人，保留研究但暂不作正式排名或无条件目标价。尚未公布的未来交易日历明确列为日期假设，公开投行新闻转述与原始报告分开标注。情景权重是研究判断，目标价与回报均取决于模型假设。网页数据固定截至2026年10月9日，不自动更新行情。

本地预览可在研究目录运行 `node tools/serve_web.cjs`，访问 `http://127.0.0.1:8769/web/index.html`。无需实时数据服务或外部部署。

网页支持按预期涨跌幅、含分红期望回报、悲观/基准/乐观收益及年底期望排序。可调整三种情景权重，实时查看加权平均、等权平均和股票对比；有效权重在浏览器保存，推荐名次保持原研究结果。权重属于主观假设，不冒充统计发生概率。
