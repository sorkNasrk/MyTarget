# MyTarget

证券研究资料与报告归档。

研究项目位于 `outputs/investment_research_20261009/`：

- `data/`：研究源资料、原始证据与结构化数据。
- `research/`：研究文本。
- `deliverables/`：Word、PDF 和 Excel 报告。
- `qa/`：审核记录、检查结果与辅助图表。
- `tools/`：研究处理、报告生成与检查脚本。

外部依赖、Python 字节码缓存、报告分页渲染缓存和 `*.inspect.ndjson` 检查临时文件由 `.gitignore` 排除，保留在本地。

当前研究数据版本为 `63ca87a2011995a6`，价格和资料截止日为2026年10月9日。92家公司、96个股票证券已完成整合，91个证券参加四期限排名，5个证券保留条件研究且暂不排名。92家正文均通过不少于1万有效汉字检查；总有效汉字约128.6万。

这一阶段完成了来源期间、币种、单位、截止日、评分、目标价和回报公式核对。Word、PDF和Excel正在进行同源数字、输入刷新及版面验收，文件尚未作为完整最终交付。

研究网页已位于 `outputs/investment_research_20261009/web/index.html`，可直接双击离线打开。支持搜索92家公司、四期限排名、96证券详情与A/H切换、最多4项比较、真实历史K线、完整正文及来源。网页数字与冻结研究模型通过86,260项一致性检查，96证券结论页及手机布局通过浏览器验证。网页会明确标注最终文件验收尚未结束。

本地预览可在研究目录运行 `node tools/serve_web.cjs`，访问 `http://127.0.0.1:8769/web/index.html`。无需实时数据服务或外部部署。
