# 证券研究台

双击 `index.html` 可离线查看。保持 `data.js`、`app.js`、`style.css`、`content` 和 `history` 同目录。

网页覆盖92家公司、96个股票证券，研究基准2026年10月9日。支持四期限排序、条件证券、公司搜索、A/H切换、最多4个股票比较、真实复权K线/成交量、完整独立正文、来源和公开投行目标。

正文和历史行情按需加载，不调用实时行情接口。全部27份导出文件已通过内容、模型、同源PDF及可读性验收，链接位于“研究文件”页面，文件保存于上一级 `deliverables`。13卷PDF共1,960页；92家正文均达到1万有效汉字。文件哈希与验收记录见上一级 `qa/final_delivery_manifest.json`。

英矽智能、开拓药业、微创医疗、微创脑科学及微创机器人属于条件研究，暂不正式排名。未来未公布交易日历、缺失的机构目标期限及其他输入限制保留明确标注。情景权重是判断假设，预期涨幅不是获利保证。

重建数据：从研究目录运行 `node tools/build_web.mjs`。网页展示的是冻结研究快照；修改Excel假设后，必须重新刷新权威模型再构建，网页不会自动改写研究结论。
